# 🚀 NextGram — Full Stack Instagram Clone

NextGram is a full-stack Instagram-style social media application built with **Next.js**, **Tailwind CSS**, **Node.js**, **Express**, and **MongoDB**.  
This repository contains both **frontend** and **backend** in a single project.

---

## 📌 Features

### Frontend
- Register / Login  
- Profile Page  
- Create Post  
- View Feed  
- Responsive UI  
- Dark Mode  

### Backend
- JWT Authentication  
- User Register / Login  
- Profile Fetch & Update  
- Post CRUD  
- Image Upload  
- Secure Password Hashing  

---

## 🧱 Tech Stack

### Frontend
- Next.js (App Router)
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT
- Multer
- Cloudinary
- bcrypt
